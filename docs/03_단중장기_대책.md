# 03. 단·중·장기 대책 & 리더십 액션 — Leadership Action Designer

> 입력: `01_진단_결과.md`, `02_병목_StopList.md`
> 원칙: 사과는 짧게, 약속은 "언제까지 무엇을 멈추겠다"로 구체적으로.

## 결론 (먼저)

- **단기(0~1개월)**는 신뢰 회복 신호입니다. Stop-List 공식 선언, 레거시 폴더 정리, 3P 회의 선언, Recognition First 즉시 적용. 모두 리더 결정만으로 가능합니다.
- **중기(1~3개월)**는 구조를 바꿉니다. GitHub 페어링, 주 2시간 Tech Time Slot, TL 중심 맥락 전달 체계, 격주 마일스톤 공유.
- **장기(3~12개월)**는 정체성과 커리어입니다. 선행·상용 로테이션, 이슈 1차 분석 필터 제도화, 평가 기준 투명화, SCI 재측정.
- 모든 대책은 **고충 카테고리 8개** 중 최소 하나에 매핑되고, 성공 지표를 가집니다.

## 2. 그룹 CA·파트 총무 간담회 오프닝 스크립트

> 실제 발화용. 5분 분량. 사과는 짧게, 약속은 구체적으로.

"오늘 자리는 제가 설명하는 자리가 아니라 듣는 자리입니다. 그 전에 세 가지만 먼저 말씀드리겠습니다.

첫째, 올해 저는 위에서 요구하는 일정을 맞추는 데 집중했고, 그 과정에서 여러분에게 **왜 하는지 설명하지 않은 채 일을 얹었습니다.** 과제는 늘었고 회의도 늘었는데 끝난 것은 적었습니다. 그 부담은 제가 만든 것입니다.

둘째, 그래서 오늘부터 **더하지 않고 빼겠습니다.** 이번 주 안에 방향이 정해지지 않은 다인원 회의와 이름만 다른 진도 회의를 없애고, 종료 기준이 없는 개선 과제는 공식적으로 보류하겠습니다. 목록은 이 자리에서 함께 확정하고, 다음 주 전체 공지하겠습니다.

셋째, 어려운 이슈를 해결하신 분께 제가 가장 먼저 한 말이 '그럼 TC 추가하시죠'였던 것을 압니다. 앞으로는 **인정이 먼저**입니다. 개선 논의는 그 뒤에, 사람이 아니라 절차를 보는 방식으로 하겠습니다.

오늘 워크숍은 세 칸입니다. 멈출 것, 시작할 것, 계속할 것. 멈출 것부터 채워주십시오. 제가 결정할 수 있는 것은 이 자리에서 결정하고, 제 권한 밖인 것은 솔직히 그렇다고 말씀드리겠습니다."

## 3. Recognition First & Blameless Post-mortem 가이드

| 단계 | 시점 | 리더 행동 | 금지 |
|---|---|---|---|
| 1. 인정 | 이슈 해결 후 24시간 내 | 그룹 채널에 공개 인정. "무엇이 어려웠고 어떻게 풀었는지"를 구체적으로 언급 | "다음엔 ~하세요" 같은 조건부 칭찬 |
| 2. 쉼 | 해결 후 1주 | 추가 요청 없음 | post-mortem 즉시 요구 |
| 3. Blameless 회고 | 1주 후, 30분 | 질문은 "누가"가 아니라 "어떤 절차·도구가 있었다면" | 개인 지목, 책임 추궁 |
| 4. 시스템 개선 | 회고 결과 | TC 추가·가이드 보강은 **팀 과제**로 등록, 해결자 개인 숙제로 만들지 않음 | 해결자에게 단독 배정 |

| 2 | 2~3주차 | TL 미팅: R&R 재정립, 과제 브리프 양식, PL/TL alignment 주기 | 과제 브리프 템플릿, TL 소통 규칙 |
| 3 | 3~4주차 | 전체 공지 + Quick-Win 1호(레거시 폴더 정리) + 3P 회의 선언 | 공지문, 정리 완료 보고 |
| 4 | 2개월차~ | Tech Time Slot 주 2시간 확보, 1on1 Action Item 대시보드 트래킹, 분기 SCI 미니 설문 | 대시보드, 분기 리포트 |

## 5. Stop-Start-Continue 워크숍 키트

| 칸 | 질문 | 작성 규칙 |
|---|---|---|
| Stop | 지금 당장 없어져도 아무도 아쉬워하지 않을 회의·과제·절차는? | 1인 3개, 익명 포스트잇 |
| Start | 한 가지만 새로 한다면? (단, Stop 1개당 Start 1개만) | 1-in-1-out |
| Continue | 지금 잘 되고 있어서 지켜야 할 것은? | 긍정 신호 5개 참고 |

진행: 15분 작성 → 15분 묶기(dot voting) → 20분 그룹장 즉석 결정(가능/불가/검토) → 5분 다음 액션. 결과는 1주 내 전체 공지.

## 6. 1on1 16-8-4 법칙

30분 기준: **16분** 구성원 발언(끊지 않음) → **8분** 리더 질문·공감("그때 어떤 점이 가장 힘들었나요") → **4분** 리더의 Blocker 제거 약속 1개(기한 포함). 자리 방문이 아니라 사전 예약으로 진행합니다.
